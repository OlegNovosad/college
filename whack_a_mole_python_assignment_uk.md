# 🐹 Python-завдання: «Удар по кроту» (Whack-a-Mole)

**Рівень:** початковий  
**Орієнтовний час:** 40–60 хвилин (плюс 15–20 хвилин на підготовку)  
**Потрібні знання:** списки, `while`, `if` / `else`, `input()`  
**Новий інструмент:** вбудований модуль `random`

## 🎯 Твоя місія

Створи **гру Whack-a-Mole у терміналі**! Кріт 🐹 з’являється в одній із дев’яти нір, а гравець повинен вибрати правильну нору. За влучання нараховується **1 бал**. Гра триває **10 раундів**.

Програма повинна змінювати ігрове поле в кожному раунді, рахувати бали та показувати підсумковий результат.

## 🎮 Приклад гри

```text
====================
    WHACK-A-MOLE
====================
Раунд 1 / 10     Бали: 0

🕳️ 🕳️ 🕳️
🕳️ 🐹 🕳️
🕳️ 🕳️ 🕳️

Обери нору (1–9): 5
ВЛУЧАННЯ! 🎯

Раунд 2 / 10     Бали: 1

🕳️ 🕳️ 🐹
🕳️ 🕳️ 🕳️
🕳️ 🕳️ 🕳️

Обери нору (1–9): 6
ПРОМАХ! ❌

...

====================
     КІНЕЦЬ ГРИ
====================
Підсумковий рахунок: 7 / 10
Чудова робота!
```

Номери нір відповідають таким позиціям:

```text
1 2 3
4 5 6
7 8 9
```

> **Важливо:** індекси списку в Python починаються з `0`, але гравець вибирає нори з номерами від `1` до `9`.

## 📚 Додаткові матеріали — прочитай перед початком

**Не потрібно читати документацію повністю.** Зосередься на наведених поняттях і коротких прикладах. Виділи приблизно **15–20 хвилин** на підготовку. Посилання ведуть на офіційну документацію Python (англійською).

### 1. Списки та індекси (обов’язково)

**Прочитай:** [Python Tutorial — Lists](https://docs.python.org/3/tutorial/introduction.html#lists)

Список зберігає кілька значень у певному порядку. Кожен елемент має **індекс**, починаючи з `0`. За індексом можна отримати або змінити елемент.

```python
holes = ["empty", "empty", "empty"]
print(holes[0])       # перша нора
holes[1] = "mole"    # змінюємо другу нору
print(holes)
```

**Спробуй:** створи список із п’яти нір і помісти крота в останню. Який індекс ти використав?

### 2. Цикл `while` (обов’язково)

**Прочитай:** [Python Tutorial — First Steps Towards Programming](https://docs.python.org/3/tutorial/introduction.html#first-steps-towards-programming) (знайди приклад із `while`)

Цикл `while` повторює команди, **поки його умова істинна**. Змінюй лічильник усередині циклу, щоб він міг завершитися.

```python
round_number = 1
while round_number <= 3:
    print("Раунд", round_number)
    round_number += 1
```

**Спробуй:** зміни програму так, щоб вона вивела п’ять раундів. Що станеться, якщо прибрати `round_number += 1`? Спочатку подумай, а не запускай нескінченний цикл.

### 3. Умови `if` та `else` (обов’язково)

**Прочитай:** [Python Tutorial — `if` Statements](https://docs.python.org/3/tutorial/controlflow.html#if-statements)

Умови допомагають перевірити, чи гравець влучив у крота.

```python
chosen_hole = 2
mole_hole = 2
if chosen_hole == mole_hole:
    print("Влучання!")
else:
    print("Промах!")
```

**Спробуй:** зміни `chosen_hole`, щоб програма вивела `Промах!`. Поясни різницю між `==` та `=`.

### 4. Введення даних і перетворення рядка на число (обов’язково)

**Прочитай:** [Python — `input()`](https://docs.python.org/3/library/functions.html#input) та [`int()`](https://docs.python.org/3/library/functions.html#int)

Функція `input()` повертає **текст**, навіть якщо користувач ввів цифру. Функція `int()` перетворює коректний запис числа на ціле число.

```python
answer = input("Обери нору (1–9): ")
hole_number = int(answer)
print("Твій вибір:", hole_number)
```

**Спробуй:** введи `4`, а потім `hello`. Що відрізняється? Пізніше ти навчиш програму обробляти некоректне введення без помилки.

### 5. Випадкові числа (обов’язково)

**Прочитай:** [Python `random` — `randint()`](https://docs.python.org/3/library/random.html#random.randint)

`random.randint(a, b)` повертає випадкове ціле число **від `a` до `b` включно**. Встановлювати модуль окремо не потрібно.

```python
import random

position = random.randint(0, 8)
print(position)
```

**Спробуй:** запусти приклад кілька разів. Чому діапазон від `0` до `8` підходить для списку з дев’яти нір?

### 6. Перевірка введення (для кроку 6)

**Прочитай:** [Python String Methods — `str.isdecimal()`](https://docs.python.org/3/library/stdtypes.html#str.isdecimal)

Перед викликом `int()` можна перевірити, чи рядок складається з десяткових цифр. **Також** потрібно впевнитися, що число належить до діапазону від 1 до 9.

```python
answer = input("Введи номер нори: ")
if answer.isdecimal():
    number = int(answer)
    print("Ти ввів число:", number)
else:
    print("Вводь лише цифри")
```

**Спробуй:** перевір `3`, `11`, `hello` та порожній рядок. Які значення ще потрібно перевіряти на допустимий діапазон?

### Швидка шпаргалка

| Можливість Python | Для чого потрібна в грі |
|---|---|
| `board = ["🕳️"] * 9` | Створити дев’ять порожніх нір |
| `board[index]` | Отримати вміст однієї нори |
| `board[index] = "🐹"` | Помістити крота в нору |
| `random.randint(0, 8)` | Вибрати випадковий індекс списку |
| `input()` | Прочитати вибір гравця |
| `int(...)` | Перетворити коректний текст на число |
| `if` / `else` | Визначити влучання або промах |
| `while` | Повторювати раунди |
| `len(board)` | Порахувати кількість нір (для розширень) |

**Перевірка готовності:** перш ніж будувати всю гру, переконайся, що вмієш створити список, змінити один елемент, виконати цикл `while` із трьох повторень і згенерувати випадковий індекс.

   - Очисть поле: усі дев’ять нір мають стати порожніми.
